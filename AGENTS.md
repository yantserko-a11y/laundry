## Что это

Сайт, где жители общежития записываются на стирку: сетка «день × время × машинка», запись на несколько машинок сразу, отмена своей записи, кнопка «в календарь», админка для отключения сломанных машинок. Языки — русский и английский.

- **Сайт для людей:** https://yantserko-a11y.github.io/laundry/ (GitHub Pages, папка `docs/` ветки `main`).
- **Бэкенд:** Google Apps Script, привязанный к Google-таблице «Стирка — записи». Опубликован как веб-приложение (Execute as: владелец, доступ: Anyone). Адрес — константа `API_URL` в `src/Index.html`.
- **Данные:** лист «Записи» той же таблицы. Квитанции — папка «Стирка — квитанции» на Google Drive владельца.

```
Браузер (github.io) ──fetch, без cookies──▶ Apps Script /exec (doGet/doPost) ──▶ Google-таблица + Drive
```

## Файлы

| Файл | Что это |
|---|---|
| `src/Code.gs` | Весь бэкенд (Apps Script, JavaScript V8). |
| `src/Index.html` | Вся страница: HTML + CSS + JS в одном файле, без фреймворков и сборщиков. **Исходник.** |
| `docs/index.html` | Копия страницы для GitHub Pages. **Генерируется** из `src/Index.html` скриптом `./build.sh` (убирает `<base target="_top">`). Руками не править — затрётся при следующей сборке. |
| `docs/manifest.webmanifest`, `docs/*.png` | Иконки и манифест для «Добавить на экран „Домой“». |
| `src/appsscript.json` | Манифест Apps Script (часовой пояс Europe/Moscow, настройки веб-приложения). |
| `src/Secrets.gs` | Соль и SHA-256 хэш пароля админки. **Нет в git** (в `.gitignore`), лежит только в проекте Apps Script и у Кристины локально. |
| `.clasp.json` | ID проекта Apps Script для утилиты clasp. |
| `build.sh` | Сборка `docs/index.html` из `src/Index.html`. |

Тот же `src/Index.html` отдаётся и самим Apps Script по прямой ссылке `/exec` (запасной вариант). Внутри Apps Script страница ходит в бэкенд через `google.script.run`, на GitHub Pages — через `fetch`. Это решает функция `call()` в `Index.html`.

## Бэкенд (`src/Code.gs`)

### Константы (в начале файла)

| Константа | Значение | Смысл |
|---|---|---|
| `MACHINES` | 6 | Машинки №1…6 |
| `SLOTS` | `10:00-12:00` … `22:00-00:00` | 7 слотов по 2 часа |
| `PRICE` | 50 | ₽ за одну стирку |
| `TZ` | `Europe/Moscow` | Все даты по Москве |
| `MAX_PER_DAY` | 6 | Лимит машинок в день на человека |
| `MAX_RECEIPT_BYTES` | 8 МБ | Максимальный размер квитанции |
| `MAX_CONTACT_LEN` | 100 | Длина поля «контакт» |
| `ADMIN_MAX_FAILS` | 10 | Неудачных входов в админку за 15 минут до блокировки |

Запись открыта **с сегодняшнего дня до ближайшего воскресенья включительно** (`days_()`). Прошедшие слоты сегодняшнего дня закрыты (`closedSlots_()`).

### Таблица, лист «Записи»

Колонки (`HEADERS` / `COL`): `ID`, `Создано`, `Дата` (dd.MM.yyyy), `Время` (слот), `Машинка`, `Фамилия и имя`, `Комната`, `Оплата, ₽`, `Квитанция` (ссылка на Drive), `Статус` (`active` | `cancelled`), `Устройство` (хэш id устройства), `Пачка` (id одной отправки), `Контакт`.

- **Новые колонки добавлять только в конец** — в таблице живые данные, сдвиг сломает старые строки.
- Значения пишутся как текст (`setNumberFormat('@')`), иначе Таблицы превращают комнату «012» в 12.
- Отмена не удаляет строку, а ставит `Статус = cancelled`. Админ может так же отменить любую запись вручную прямо в таблице.

### API

Все ответы — JSON `{"result": …}` или `{"error": "ERR_…"}`. Тексты ошибок переводит страница по коду.

**GET** `/exec?action=state&device=<id>` → состояние недели:

```json
{ "today": "10.11.2026", "days": ["10.11.2026", "…"], "slots": ["10:00-12:00", "…"], "machines": 6,
  "price": 50, "maxPerDay": 6, "closed": ["10:00-12:00"], "disabled": { "5": "" },
  "taken": [{ "id": "a1b2c3d4", "date": "10.11.2026", "slot": "12:00-14:00", "machine": 2,
              "name": "Иванова Мария", "contact": "@masha", "mine": false }] }
```

**POST** `/exec`, тело — JSON, `Content-Type: text/plain` (именно text/plain — так нет CORS-preflight, который Apps Script не умеет):

- `{"action":"book","deviceId","name","room","contact","consent":true,"cells":[{"date","slot","machine"}],"receipt"?:{"name","mime","base64"}}` → `{"ok":true,"state":…}` или `{"ok":false,"conflicts":[…],"state":…}`, если ячейку успели занять.
- `{"action":"cancel","deviceId","id"}` → новое состояние. Отменить можно только запись своего устройства (`ERR_NOT_MINE`).
- `{"action":"admin","password","op":"login"}` → `{"disabled":{…}}`.
- `{"action":"admin","password","op":"setMachines","machines":{"5":""}}` — список **неработающих** машинок; всех остальных считаем рабочими. Хранится в Script Properties (`disabled`), действует на все дни, пока админ не включит обратно.

Коды ошибок: `ERR_PROFILE`, `ERR_CONSENT`, `ERR_EMPTY`, `ERR_LIMIT`, `ERR_MACHINE_OFF`, `ERR_NOT_MINE`, `ERR_FILE_SIZE`, `ERR_ADMIN_PASSWORD`, `ERR_ADMIN_LOCKED`, `ERR_ADMIN_OFF`, `ERR_ACTION`. Новый код ошибки → добавить перевод в оба языка в `I18N` на странице.

### Важные детали бэкенда

- Запись идёт под `LockService` — двое не займут одну ячейку.
- Лимит `MAX_PER_DAY` считается на «человека»: то же устройство **или** та же пара «имя + комната».
- Пароль админки проверяется по соли и хэшу из `Secrets.gs`. Сменить пароль: сгенерировать новую соль, посчитать `base64(sha256(соль + пароль))`, записать в `Secrets.gs` в редакторе Apps Script и опубликовать новую версию.
- **Еженедельная очистка:** триггер `weeklyReset` в ночь на понедельник (~00:00 МСК) удаляет записи прошедших дней. Триггеры принадлежат конкретному Google-аккаунту. Если сменился владелец — от имени нового владельца запустить `reinstallTrigger` в редакторе Apps Script.

## Фронтенд (`src/Index.html`)

Один файл, чистый JS. Главное:

- `I18N` — все тексты на `ru` и `en`. **Любой новый текст добавлять в оба языка** с одинаковыми ключами.
- `call(fn, …)` — вызов бэкенда (`getState`, `book`, `cancel`, `adminApi`).
- `renderGrid()` — сетка; `onCell()` — клик по ячейке (выбор, лимит, «кто записан», отмена своей).
- `openWho()` — карточка «кто записан»: имя, время, машинка, контакт (ссылки только для `@ник`, `t.me/…`, `vk.com/…`).
- Календарь: `groupEvents()`, `buildICS()` (файл .ics, напоминания за 10 минут и в конце), `googleLink()`. Во встроенных браузерах iPhone (Telegram и т. п.) .ics не открывается, поэтому `openInSafari()` открывает Safari ссылкой `x-safari-https://…?ics=…`, а `handleIcsParam()` там показывает кнопки календаря.
- `renderInstall()` — подсказка «на экран „Домой“» для iPhone/Android, закрывается крестиком.
- Админка: ссылка «Администратору» внизу страницы → пароль → галочки «работает» у машинок.
- Автообновление состояния раз в 30 секунд и при возврате на вкладку.

Хранилище браузера: `localStorage` — `laundry.device` (случайный id устройства, по нему «моё» и отмена), `laundry.profile` (имя, комната, контакт), `laundry.lang`, `laundry.consent`, `laundry.installHidden`; `sessionStorage` — `laundry.admin` (пароль до закрытия вкладки).

## Правила, которые нельзя нарушать

1. **Номер комнаты нигде не показывать на сайте и не отдавать из API** — ни в сетке, ни в карточке записи. Комната есть только в Google-таблице.
2. Пароль админки, соль и хэш не коммитить в git (репозиторий публичный).
3. Не создавать новое развёртывание Apps Script — только обновлять существующее, иначе сменится адрес `/exec` и сайт перестанет работать.
4. Публиковать бэкенд только из аккаунта **Lensovetik**. Веб-приложение выполняется от имени того, кто опубликовал версию.
5. Страница должна ходить в Apps Script через `fetch(..., { credentials: 'omit' })`. Прямая ссылка на Apps Script ломается («Не удалось открыть файл»), если в браузере вошли в несколько Google-аккаунтов.
6. Колонки таблицы — только добавлять в конец.
7. Все тексты — на двух языках.

## Как выложить изменения

### Фронтенд (страница)

1. Поправить `src/Index.html`.
2. Запустить `./build.sh` (обновит `docs/index.html`). Без терминала: сделать ту же правку и в `docs/index.html`, не трогая там отсутствие строки `<base target="_top">`.
3. Закоммитить и запушить в `main`. GitHub Pages обновится за 1–2 минуты; браузеры могут держать старую версию до 10 минут.
4. Если правка нужна и запасной странице на Apps Script — выложить и бэкенд (см. ниже), там тот же `Index.html`.

### Бэкенд

**Вариант А — без компьютера, в браузере:**
1. Войти в Google как Lensovetik, открыть таблицу «Стирка — записи» → «Расширения» → «Apps Script».
2. Поправить `Code.gs` (или `Index.html`), сохранить.
3. «Развертывание» → «Управление развертываниями» → ✏️ у активного развёртывания → «Версия: новая» → «Развернуть». Адрес останется прежним.
4. Если правили в редакторе, перенести те же правки в `src/` на GitHub (или попросить того, у кого есть доступ, сделать `clasp pull`), иначе следующая выкладка с компьютера их затрёт.

**Вариант Б — с компьютера через clasp** (Node.js + `npm i -g @google/clasp`, вход: `clasp login --user lensovetik`, в аккаунте должен быть включён Apps Script API на https://script.google.com/home/usersettings):

```bash
clasp pull --user lensovetik          # если кто-то правил в редакторе
clasp push -f --user lensovetik
clasp update-deployment AKfycbx0ZgqzJRiuFUDiF7XprkQcve19oIhvDXlNq8Top7QLdTUy67wMFeqOhRVYzm-RmeTsdw --user lensovetik
```

`src/Secrets.gs` есть только у владельца. Если его нет локально, `clasp push -f` удалит его из проекта и админка перестанет пускать: сначала `clasp pull`.

## Как проверить

Автотестов нет. Проверять в браузере на ширине телефона (~375 px):

- **Без бэкенда:** открыть `src/Index.html` через локальный сервер (`python3 -m http.server`), подложив перед основным скриптом заглушку `window.google = { script: { run: … } }`, которая отвечает на `getState`, `book`, `cancel`, `adminApi` тестовыми данными в формате из раздела «API». Тогда страница работает без интернета и без риска для реальных записей.
- **На живом сайте:** тестовые записи делать с именем `TEST` и сразу отменять.
- Пройти: выбор нескольких ячеек → «Записаться» → экран «Готово» с календарём → тап по своей записи → отмена; тап по чужой записи (без комнаты!); лимит 6 в день; выключенная машинка в админке; переключение RU/EN.
